# Native Messages, ACE host observation, and ACMA reference attention

The desktop preset now uses Anthropic Messages against the loopback gateway root. Native FreeToken generation and count_tokens share the Anthropic prompt conversion; count requests include tool definitions and tool results. Gateway checks tool pairing, output reserve and native window before generation; SSE is forwarded. Tool execution remains with Harness and its permission/sandbox controls. Text/tool blocks only; image and unsupported server-side tools rejected. Cache annotations and extended-thinking budgets require further parity testing. No arbitrary remote route or shell execution was added. Existing OpenAI text route remains.

The pinned Harness compaction-basic overlay calls the read-only ACE endpoint at its local-provider pressure boundary. It sends token meter totals and the token estimate of a balanced candidate span, never content. It resolves the existing provider credential and contacts only loopback. Stats field paths follow FreeToken server/stats.py; missing stats or task metadata does not grant compaction consent. Automatic pressure and overflow mutation for local-longctx are held pending the complete metadata/consent integration; native explicit manual compaction remains a separate action. Nonlocal provider behavior is unchanged. On a local model switch requiring a reduction, fail rather than silently summarize. The Python endpoint can evaluate the full ACE policy if given explicit estimates and candidate metadata; the current host observer does not supply them. It does not mutate history. Future authorized auto-compaction must invoke native compactRegion with fresh range and session checks, force a local summarizer, and preserve native replay/transaction semantics. It must not create a parallel source of truth in the SQLite archive.

CPU reference kernel uses online softmax with bounded per-page working memory; page bounds and top-k candidate selection are separate approximate experiments. All-pages mode is mathematically exact up to floating-point error for a single visible query. No causal mask, RoPE, model-specific layouts, or GQA integration yet. No speed claims or CUDA replacement. Next: pinned FreeToken native attention adapter, tensor/page formats, exact reference parity across layouts, quantized cache error and routing recall, GPU memory and throughput benchmark, then SSD paging. Never label sparse attention as full attention.
