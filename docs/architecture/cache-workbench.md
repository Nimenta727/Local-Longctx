# V5.2 — cache workbench and research gates

Screenshot-inspired native settings: model import, native window, startup KV tokens, expert slots, prefill chunk, output reserve, threads, VRAM ratio, KV dtype; runtime KV/MoE/SWA/GDN pool sliders and numeric controls use reported geometry, page size, unit costs and limits. Cache budget is a combined estimate; native engine accounts fixed overhead. Idle-only native rebuild with revision check, explicit native confirmation and shared inference lock. Live changes are not persisted across restart; no arbitrary backend URL or shell. No automatic resize under pressure. RAM/VRAM and backend throughput are read-only. Model metadata does not prove a million-token active request fits; separate model window and resident capacity. GUI model library is still single imported model, not a catalog/download manager.

FreeToken upstream inspected: https://github.com/FlashML-org/FreeToken/blob/main/docs/cli.md and https://github.com/FlashML-org/FreeToken/blob/main/python/freetoken/server/api_server.py. Version must be pinned before production; unknown geometry fails closed. Full cache rebuild may invalidate prefix reuse. Do not use on a busy agent or without a recovery plan.

P0: native_tool_smoke.py tests real local Messages counting and one harmless tool roundtrip; actual Harness tool execution, streaming and permission tests remain. verify_build.py runs tests/typecheck/build after dependencies installed in pinned source; upstream requires Node ^24.22.3 or >=26.13.1 and pnpm 11.28.5. Current runner lacks required toolchain/network/GPU. ACE host observer remains read-only; no invented task-dependency scores, no automatic mutation. Implement per-session metadata and consent, force local summary route, check balanced span and generation before commit, then replay and restore tests.

P1: CUDA tensor-operation streaming attention prototype and dense check benchmark, not custom fused CUDA or production integration. 4/8-bit CPU packed per-vector quantization with FP32 scale and simple mixed-bit policy, not FreeToken layout. Query-aware page selection remains previous reference; compare recall and full-attention error before activation.

P2: bounded RAM/SSD opaque page store with content hash, atomic file write and RAM LRU; no GPU DMA, native KV export/import, persistence index or cross-process concurrency. CUDA prototype streams CPU pages to GPU synchronously; no SSD→GPU path. Next: pin native backend, implement aligned page formats and lifecycle, VRAM allocator integration, asynchronous transfers, mixed precision/sparse attention correctness, real 8K→1M experiments. Never label logical history as full native attention.
