# Verification gates
Run python -m unittest discover -s tests -v. Written tests are not proof of actual execution. Test strict config, unavailable GPU, native token parity, ACE consent/quality/idle/cost/forecast/workspace gates. Replay recorded telemetry versus fixed threshold and no compaction. Measure TTFT, decode TPS, peak RAM/VRAM, cache hit, actual prefix replay and retrieval/multi-hop quality. Test stale snapshots and missing fields. Native rebuild and semantic transaction require independent validation. Test only within verified model window, no silent truncation. Pin upstream and validate Windows/Linux before release.
